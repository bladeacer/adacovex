Date: _2026-11-05_

## Changes

### C1: Proof-coverage summary is on by default for plain `adacovex`

A plain `adacovex` run already parsed cached gnatprove artefacts but never
printed the proof-coverage summary line, while `adacovex prove` did. Both
entry points now print the statement, subprogram, and VC coverage line by
default when proof data is available. `--no-coverage` hides it for one run,
`[prove] coverage = false` in `adacovex.toml` hides it for every run, and an
explicit `--coverage` wins over the config file. The default matches
`adacovex prove`, so a user never has to opt in to see it.

`Adacovex.Prove.Report_Coverage` is declared in the package spec so both the
prove subcommand and the plain pipeline can call it.

### C2: Timestamps are stored as UTC+0 unless the user opts into the local zone

`adacovex status` and the local date/time reports now default to `UTC+00:00`
instead of the operating system's wall-clock timezone. The operator's local
zone is only used when the user explicitly opts in with `--tz=local` (or
`--timezone=local`). Any other explicit spec -- a named IANA zone like
`Asia/Singapore` or a fixed offset like `UTC+8` -- still wins, and a bad
value fails loudly. `Adacovex.Timezones.Default` returns UTC+0; the previous
OS-zone behaviour moved to `Default_Local`, which `Effective_TZ` calls only
when `Is_Local_Spec` matches `--tz=local`.

### C3: Docstrings carry descriptions for every public API surface

The API reference pages generated by `just doc` no longer list a parameter
or return value with an empty Description cell. `Adacovex_Man_Tests.Run` and
its `R` parameter, the four `Adacovex.Timezones` functions added in this
release, and the public subprograms touched by the coverage and timezone
changes all document their parameters and return values. The front-loaded
docstring pass continues across v1.69.0 and v1.70.0; a generated page shows
a description unless the docstring itself is empty.

## Test Suite

Added coverage-default checks to `tests/e2e/cli_flags.py`
(`check_config_prove`): the summary is present by default, hidden by
`--no-coverage`, forced by `--coverage`, and shown by plain `adacovex` from
cached proof artefacts. Added timezone checks to
`src/tests/adacovex_tz_ansi_tests.adb` (default is UTC+00:00,
`Default_Local` is within UTC-14:00..UTC+14:00, `Is_Local_Spec` matches
`local` case-insensitively with padding ignored and rejects every other spec)
and `tests/e2e/cli_flags.py` (`check_timezone`: default status timestamp is
UTC+00:00, `--tz=local` with `TZ=Asia/Singapore` reports Asia/Singapore,
`--tz=UTC+8` reports UTC+08:00).

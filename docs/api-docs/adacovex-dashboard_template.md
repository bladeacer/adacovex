# Adacovex.Dashboard_Template

Generated by tools/gen-dashboard.py from resources/dashboard.html
plus the resources/ modules it inlines (css/dashboard.css, js/theme.js, js/tabs.js,
js/deps.js, js/details.js, js/nomnoml.js, js/search.js, graphre.js, nomnoml.js,
flexsearch.js) --
a single bundled dashboard page shell for --serve: the static
HTML/CSS/JS (dynamic metric cards are injected at the **CARDS**
placeholder by Adacovex.Renderers.HTML.Render_Dashboard, which
also fills the **THEME** placeholder with the initial dashboard
theme).  Do not edit by hand; edit resources/ and run make build.

> **Note:** All items in this package are public.
